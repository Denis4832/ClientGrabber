ЛОКАЛЬНЫЙ MINECRAFT-ПРОКСИ С ПОДРОБНЫМИ ЛОГАМИ

ЗАПУСК
  Дважды нажмите start.bat или start-server.bat.
  Не закрывайте консоль во время игры: через неё идёт соединение с сервером.
  В Minecraft Java Edition подключитесь к localhost:25565.
  Для остановки сначала выйдите с сервера, затем нажмите Ctrl+C в консоли.
  Требуется Java 17 или новее. Готовый JAR включён; для пересборки нужен JDK 17+.
  Перед запуском скопируйте localplayerlogger-proxy.properties.example в файл
  localplayerlogger-proxy.properties и замените backend_host своим адресом.
  Если конфига нет, первый запуск создаст его из примера и попросит настроить сервер.

СЕРВЕР НАЗНАЧЕНИЯ
  Настройки: server\proxy\localplayerlogger-proxy.properties
  backend_host/backend_port — куда устанавливается TCP-соединение.
  upstream_host/upstream_port — адрес сервера в начальном Minecraft handshake.
  Для обычного подключения обе пары должны указывать один сервер.
  По умолчанию указан сервер-заглушка: server.example.invalid:25565.
  upstream_host/upstream_port можно не задавать: они берутся из backend_host/backend_port.
  listen_host=127.0.0.1 означает, что подключение доступно только с этого компьютера.

ВЕРСИИ
  Это прозрачный прокси, а не отдельный игровой сервер и не переводчик версий.
  Войти можно с версий, которые принимает сервер назначения.
  Подробная расшифровка движений: 1.16.5, 1.21.4, 1.21.5, 1.21.6,
  1.21.7/1.21.8, 1.21.9/1.21.10, 1.21.11 и 26.1 (совместимый протокол 26.1.x).
  У неизвестных протоколов исходный трафик сохраняется; консоль предупреждает,
  что подробная расшифровка для этой версии недоступна.

ЛОГИ
  server\session-logs\<дата_и_идентификатор_подключения>\
  Каждый вход, а также запрос из списка серверов создаёт отдельную папку.
  movements.jsonl — каждое полученное движение: координаты, yaw/pitch, дельты,
    интервалы, расстояние, скорость по координатам, направление взгляда,
    onGround, горизонтальное столкновение, известный ввод и состояние игрока.
  actions.jsonl — атаки, взаимодействия, спринт, приседание, ввод, слот и другие пакеты действий.
  client_to_server.jsonl / server_to_client.jsonl — все пакеты, их имена,
    доступные поля и исходные байты Base64. Сложные поля могут оставаться сырыми.
  *.bin — исходные принятые потоки. Изменённый handshake отдельно записан в events.jsonl.
  events.jsonl — вход, сжатие, шифрование, кики, сетевые ошибки, отключение.
  metadata.json — версия, игрок и сведения о сессии.
  Подробное описание: LOG_SCHEMA_FOR_AI.md.
  Запись на диск выполняется отдельно от передачи трафика; сброс буферов — раз в 100 мс.
  При обычном выходе очередь логов дописывается. Не завершайте процесс принудительно.
  При неисправном/слишком медленном диске игра продолжает работать, а остановка
  записи явно показывается красным в консоли и отмечается в metadata.json.

ОШИБКИ И ОГРАНИЧЕНИЯ
  Причина кика от сервера передаётся в игру без изменения и выводится в консоль.
  При локальной сетевой ошибке прокси отправляет понятную причину в игру,
  если клиент ещё подключён и протокол позволяет сформировать сообщение.
  При шифровании исходные байты продолжают передаваться и записываться,
  но движения внутри зашифрованного соединения расшифровать нельзя.
  Это реальные сетевые наблюдения, а не данные каждого кадра/клавиши или Bukkit-события.
  Серверные тики, коллизии мира, здоровье других сущностей и точные попадания
  не вычисляются из воздуха. Скорость — оценка по времени наблюдения пакетов.
  Если сервер отправит transfer на другой адрес, клиент может подключиться
  к нему напрямую: для продолжения записи подключайтесь через localhost.

ПРОЗРАЧНОСТЬ
  Прокси не добавляет серверу метку о своём присутствии, не посылает PROXY-заголовок,
  не меняет бренд клиента, чат, подписи и игровые пакеты.
  Адрес/порт в первом handshake заменяются на адрес назначения;
  остальное содержимое трафика передаётся без изменений.
  Гарантировать полную незаметность невозможно: сервер может анализировать
  задержки, тайминги и поведение соединения.
