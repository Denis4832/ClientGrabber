# ClientGrabber

Локальный прокси для Minecraft Java Edition с подробной записью перемещений и
действий игрока. Клиент подключается к `localhost:25565`, а прокси пересылает
соединение на указанный вами сервер.

## Быстрый запуск на Windows

1. Установите Java 17 или новее. Можно указать каталог Java в `JAVA_HOME`.
2. В папке `server/proxy` скопируйте
   `localplayerlogger-proxy.properties.example` в `localplayerlogger-proxy.properties`.
3. В созданном файле замените `backend_host=server.example.invalid` адресом
   вашего сервера. При необходимости измените `backend_port`.
4. Запустите `start.bat` и подключитесь в Minecraft к `localhost:25565`.

Если конфигурация отсутствует, первый запуск создаст её из примера и остановится
с понятной подсказкой. Адрес `server.example.invalid` — заглушка, подключение к ней
не выполняется. Оставьте консоль открытой во время игры. Для завершения сначала
выйдите с сервера, затем нажмите Ctrl+C в консоли.

Готовый `server/proxy/LocalPlayerLoggerProxy.jar` включён в проект. JDK и Node.js
для обычного запуска не нужны. После изменения исходников выполните сборку:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build-plugin.ps1
```

Или запустите `start-server.ps1 -Rebuild`. Для сборки требуется JDK 17+;
сторонние библиотеки не скачиваются.

## Настройка

| Параметр | Назначение |
| --- | --- |
| `listen_host` | Локальный адрес; по умолчанию `127.0.0.1` |
| `listen_port` | Порт для входа из Minecraft; по умолчанию `25565` |
| `backend_host` | Адрес сервера назначения, который нужно указать самому |
| `backend_port` | Порт сервера назначения; по умолчанию `25565` |
| `upstream_host`, `upstream_port` | Необязательный виртуальный адрес в handshake; по умолчанию совпадает с backend |

Рабочий файл конфигурации исключён из Git и публикации. В репозиторий входит
только пример с заглушкой, поэтому настроенный вами сервер не попадёт в коммит
при обычном `git add .`.

## Что записывается

Каждое подключение создаёт папку в `server/session-logs`:

- `movements.jsonl`: координаты без округления, yaw/pitch, дельты, интервалы,
  расстояния, оценка скорости, вектор взгляда, onGround, столкновение и известный ввод;
- `actions.jsonl`: спринт, приседание, атаки, взаимодействия, слот и прочие действия;
- `client_to_server.jsonl`, `server_to_client.jsonl`: имена пакетов,
  доступные расшифрованные поля и полные байты Base64;
- одноимённые `.bin`: принятые бинарные потоки;
- `events.jsonl`, `metadata.json`: сведения о сессии, кики и ошибки.

Запись на диск выполняется отдельно от сетевых потоков. Буферы сбрасываются
раз в 100 мс, при обычном выходе очередь дописывается. При ошибке диска или
переполнении очереди запись явно останавливается, а игра продолжает работать;
неполнота отмечается в metadata и красным сообщением в консоли.

Подробное описание полей: [LOG_SCHEMA_FOR_AI.md](LOG_SCHEMA_FOR_AI.md).

## Версии и ограничения

Прокси сохраняет номер версии клиента и не переводит протоколы. Сервер назначения
должен сам принимать эту версию. Подробный декодер поддерживает протоколы 754 и
769–775: 1.16.5, 1.21.4–1.21.11, 26.1 и совместимые выпуски. Неизвестные версии
сохраняются как исходные пакеты без вымышленных полей движения.

При шифровании пересылка и запись байтов продолжаются, но расшифровка движений
недоступна. Время наблюдения пакетов не равно серверным тикам, а рассчитанная
скорость зависит от задержек и объединения пакетов в сети. Полной модели мира,
серверных коллизий и точного raycast здесь нет.

Игровые пакеты, подписи и бренд клиента не меняются. В начальном handshake
корректируются адрес и порт назначения. Абсолютная незаметность прокси не
гарантируется. Серверный transfer на другой адрес может увести клиента мимо
локального прокси; для записи подключайтесь через localhost.

Логи содержат ники, чат, команды и другие данные игровой сессии. Храните их
локально; используйте запись для своих подключений и согласованных тестов.

## Проверки и публикация

Для сетевых тестов нужен Node.js 18+ и Java 17+ в `JAVA_HOME`/`PATH`:

```powershell
node --test tests/integration.mjs
node tests/launcher-smoke.mjs
node tests/publication-smoke.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File .\package-release.ps1
```

Последняя команда создаёт `dist/ClientGrabber.zip` по явному списку
`publication-files.txt`. Логи, рабочая конфигурация, резервные копии, диагностика,
старые серверные миры и кэши в архив не входят. Для публикации используйте этот
архив или файлы, отслеживаемые Git, а не всю рабочую папку.

Источники таблиц протокола: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
